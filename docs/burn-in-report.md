## Full day, host model (font-accurate)

Generated by `python3 tests/host/burnin_report.py 1440` with device fonts (Bionic_Medium / Roboto-Regular / RobotoCondensed-Regular from the SDK manager): 1440 consecutive one-minute low-power updates from 00:00, hour and minute colour white (worst case), steps 88,888, 24 h clock. With the device fonts the model is within 0.1 percentage point of the real frames above for Small/Medium/Large and within 0.3 point for X-Large/XX-Large (the model draws a different date text).

Limits (AMOLED FAQ / UX guidelines): < 10 % of pixels on, < 10 % luminance (Venu 2 and later), no pixel on for more than 3 minutes.
