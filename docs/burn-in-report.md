# Always-on burn-in report

Limits (AMOLED FAQ / UX guidelines): < 10 % of pixels on, < 10 % luminance (Venu 2 and later), no pixel on for more than 3 minutes.

Every percentage is a share of the ROUND screen (pixels inside the circle), the conservative denominator: neither the AMOLED FAQ ("10% of the screen pixels") nor `DeviceSettings.requiresBurnInProtection` ("ten-percent of the total available screen pixels") defines it for round screens (DECISIONS.md D-43).
